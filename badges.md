# Workout Widget — Badge Icon Reference

Each badge needs a square icon image (suggest 200×200 px, transparent PNG).
The icon should feel **epic, mature, and powerful** — think Greek mythology, dark fantasy, comic book art.
Style guide: bold outlines, dramatic lighting, no cartoons, no kids-style art.

## DELIVERY FORMAT

For each badge, generate a **200×200 px transparent PNG** named by the badge ID.
Example filenames: `s1.png`, `m1.png`, `w100.png`, `v10m.png`, etc.

Style: dark fantasy / Greek mythology aesthetic, bold outlines, dramatic lighting, NO cartoons.
Background: transparent. The app will display these on dark card backgrounds.
